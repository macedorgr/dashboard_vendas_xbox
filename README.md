🎮 Dashboard de Análise de Vendas - Xbox

📌 Visão Geral do Projeto

Este projeto consiste em um Dashboard Interativo desenvolvido a partir da análise da base de dados dashboard_xbox.xlsx. O objetivo principal é fornecer uma visualização clara, dinâmica e analítica do desempenho de vendas, receita e comportamento de pagamento ao longo do período analisado.

🚀 Funcionalidades e Indicadores Analisados (KPIs)

O dashboard apresenta as seguintes métricas e visualizações essenciais:

Visão Geral de Desempenho:

Receita Total: Valor bruto consolidado das vendas.

Volume de Vendas: Total de unidades vendidas.

Ticket Médio: Valor médio gasto por transação.

Análise por Produto e Preço:

Desempenho comparativo entre as linhas de produtos (Produto A, B, C e D).

Ranking de produtos por faturamento total e volume acumulado.

Análise Temporal:

Evolução de vendas por Mês e Ano.

Identificação de sazonalidade e picos de receita.

Análise por Forma de Pagamento:

Distribuição da receita de acordo com o método de pagamento selecionado (Cartão de Crédito, Boleto Bancário, etc.).

🛠️ Ferramentas e Tecnologias Utilizadas

Microsoft Excel: Trata e consolida a base de dados, utilizando Tabelas Dinâmicas, Fórmulas (SOMASES, PROCX/VLOOKUP) e Segmentadores de Dados (Slicers) para interatividade.

Markdown: Documentação e apresentação estruturada do projeto.
